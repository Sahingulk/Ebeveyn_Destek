

# 🚀 İlk Uygulamam: Ebeveyn Destek Uygulaması

Bu proje, benim ilk mobil uygulama deneyimimdi ve baştan sona tek başıma geliştirdim. Amacım, ebeveynlerin çocuklarının akademik hayatını daha kolay takip edebilmesi ve öğretmenlerle iletişimini güçlendirmesi için kapsamlı bir platform oluşturmaktı. Bu uygulama, ebeveynlerin ve öğrencilerin eğitim sürecine aktif olarak dahil olmasını sağlıyor.

-----

## ✨ Temel Özellikler

Bu uygulamayı geliştirirken odaklandığım temel özellikler şunlardı:

  * **Ebeveynler ve Öğretmenlerle Etkili İletişim**: Ebeveynlerin, çocuklarının akademik ilerlemesi hakkında öğretmenlerle hızlıca iletişim kurmasını sağlayan bir sistem oluşturdum.
  * **Kapsamlı Akademik Performans İzleme**: Ebeveynlerin çocuklarının sınav ve deneme sonuçlarını detaylı bir şekilde görebilmesi, eksiklerini belirleyip kişiselleştirilmiş bir eylem planı hazırlayabilmesi için gerekli altyapıyı kurdum.
  * **Öğrencilere Özel Eğitim Kaynakları**: Öğrencilerin zorlandığı konularda, **eğitim videoları** gibi özel olarak hazırladığım kaynaklara erişim imkanı sunarak öğrenmelerini desteklemeyi hedefledim.
  * **Akıllı Takvim ve Hatırlatıcılar**: Öğrencilerin programlarını düzenlemesi ve önemli tarihleri (sınavlar, etkinlikler vb.) kaçırmaması için otomatik hatırlatıcılar ekledim.

-----

## 🛠️ Kullanılan Teknolojiler

Bu projeyi geliştirirken aşağıdaki teknolojileri kullandım:

  * **Dart**: Uygulamayı geliştirirken ana programlama dili olarak Dart'ı kullandım. Hızlı ve etkili yapısı sayesinde işimi çok kolaylaştırdı.
  * **Flutter**: Kullanıcı dostu ve performanslı bir mobil uygulama oluşturmak için Flutter çerçevesini tercih ettim.
  * **NoSQL**: Uygulamanın veritabanı için esnek ve yüksek performanslı bir NoSQL veritabanı kullandım. Bu sayede verileri daha hızlı yönetebildim.
  * **Git & GitHub**: Kodumun tüm aşamalarını kontrol etmek ve takip etmek için Git ve GitHub'ı kullandım.
  * **ChatGPT**: Kodumda takıldığım yerlerde ve çözüm yolları ararken ChatGPT'den destek aldım.

## 🚀 Kurulum

Projeyi kendi bilgisayarınızda çalıştırmak isterseniz aşağıdaki adımları izleyebilirsiniz:

1.  Projeyi kopyalayın:
    ```bash
    git clone https://github.com/Sahingulk/Ebeveyn_Destek.git
    ```
2.  Proje klasörüne girin:
    ```bash
    cd Ebeveyn_Destek
    ```
3.  Gerekli tüm paketleri yükleyin:
    ```bash
    flutter pub get
    ```
4.  Uygulamayı çalıştırın:
    ```bash
    flutter run
    ```
